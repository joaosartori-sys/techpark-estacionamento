# TechPark - Sistema de Estacionamento

Sistema via terminal desenvolvido em Python para controle de fluxo e cobrança de estacionamento.

## Funcionalidades
- Entrada de veículos: Registro por ID e horário
- Controle de vagas: Limite de 10 vagas simultâneas
- Cálculo de tarifa: Cobrança proporcional (R$ 10,00/hora)
- Caixa: Recebimento do valor e cálculo de troco
- Validação: Tratamento de erros de digitação (try/except)

## Tecnologias
- Python 3

## Como Executar
1. Certifique-se de ter o Python instalado.
2. Execute o arquivo no terminal:
   python main.py
